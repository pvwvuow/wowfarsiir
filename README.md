# wowfarsi.ir — Persian World of Warcraft Database

The public static site served at **https://wowfarsi.ir** (GitHub Pages):
pages, styles, icons and the data files the browser loads.

The build pipeline, translation tooling, bots and internal docs live in the
private source repository (`pvwvuow/wow`) — its workflows build generated
pages/data and push updates into this repo.
